# HoloDub Project Roadmap (迁移自 optimization-roadmap.md)

## 项目背景
HoloDub（幻读）是一个自托管视频翻译与 AI 配音工具箱。
- 仓库：F:\HoloDub，GitHub: YuehaoDai/HoloDub
- 技术栈：Go (Gin+GORM) + Python (FastAPI+PyTorch) + Vue 3 + PostgreSQL + Redis + Docker
- 核心能力：智能语义切分 + IndexTTS2 时长感知配音 + 说话人→音色映射
- 流水线 7 阶段：media → separate → asr_smart → segment_review → translate → tts_duration → merge
- 长视频三层级：Episode → Chapter → Segment
